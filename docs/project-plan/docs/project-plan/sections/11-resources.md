\# 11. Risorse



Per l'esecuzione del progetto "Kranki" sono state stimate e allocate le seguenti risorse hardware, software e umane.



\## 11.1 Risorse Hardware

Essendo un'applicazione desktop, lo sviluppo e il test avverranno sulle macchine personali dei membri del team:

\* 4 Personal Computer portatili.

\* Connessione internet standard per l'accesso ai servizi cloud e alle repository.



\## 11.2 Risorse Software e Servizi Cloud

\* \*\*Ambienti di Sviluppo:\*\* Eclipse IDE, Scene Builder.

\* \*\*Tool di Modellazione:\*\* StarUML v5 (licenza gratuita/studenti).

\* \*\*Backend as a Service (BaaS):\*\* Firebase (Tier gratuito "Spark Plan" sufficiente per i carichi di test previsti in fase di sviluppo per Authentication e Firestore).

\* \*\*Gestione Progetto:\*\* GitHub (Repository remoto, Kanban board tramite GitHub Projects per il tracciamento degli Issue).



\## 11.3 Risorse Umane

Il progetto richiederà l'impiego a tempo parziale di 4 studenti del corso di Ingegneria del Software.
