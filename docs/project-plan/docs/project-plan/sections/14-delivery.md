## 14. Consegna

Le procedure di rilascio e consegna del progetto al committente seguiranno rigorosamente le linee guida definite per la valutazione accademica. La consegna non prevederà l'invio di archivi compressi una tantum, ma coinciderà con lo stato finale della repository GitHub al termine della fase di *code freeze*. 

Il pacchetto di rilascio (deliverables) includerà:
* **Codice Sorgente**: l'intera *codebase* del sistema funzionante, opportunamente versionata. La repository includerà i file di configurazione degli ambienti di sviluppo (es. i file `.project` di Eclipse) e farà un uso corretto del file `.gitignore` per escludere i file generati e non necessari.
* **Documentazione**: un unico file in formato PDF, organizzato in capitoli, contenente la specifica dei requisiti, la documentazione architetturale e di design, e i report delle attività di testing e manutenzione.
* **Presentazione e Live Demo**: redazione delle slide di presentazione dell'applicativo (utilizzando l'apposito *template* fornito dalla committenza). Il team predisporrà inoltre un terminale (PC) configurato per l'esecuzione di una dimostrazione pratica (*live demo*) del software durante la sessione d'esame orale.
